# Memory Game

Игра на поиск пар. 16 карточек (8 пар), перемешанных случайно. Открывайте по две карточки и находите все совпадения за наименьшее число ходов.

## Возможности

* Игра стартует автоматически при загрузке страницы; счётчики ходов и найденных пар.
* Несовпавшая пара закрывается через 1 секунду; пока она открыта, другие карточки выбрать нельзя.
* Кнопка «Новая игра» перезапускает игру сразу, в том числе при открытой несовпавшей паре.
* Модальное окно победы с итоговым числом ходов.
* Таблица лидеров (топ-10) в `localStorage`: место, ходы, дата (ДД.ММ.ГГГГ).
* Модальные окна закрываются кнопкой «Закрыть», кликом по фону и клавишей Escape.
* Вся разметка создаётся через JavaScript (`document.createElement`), `<body>` в `index.html` содержит только `<script>`.

## Технологии

HTML, CSS, JavaScript (ES-модули), без сторонних библиотек.

## Локальный запуск

Приложение использует ES-модули, поэтому его нужно открывать через локальный сервер, а не двойным кликом по файлу.

```bash
git clone <repo-url>

cd memory-game

git checkout memory-game

npm start          # или: python3 -m http.server 8080
```

Откройте адрес из консоли (для `npm start` обычно http://localhost:3000, для Python — http://localhost:8080).

## Структура

```text
index.html            # только <script>
src/main.js           # игровая логика и построение интерфейса
src/dom.js             # обёртка над document.createElement
src/cards.js           # данные карточек, перемешивание Фишера — Йейтса
src/modal.js           # общий компонент модального окна
src/leaderboard.js     # localStorage и таблица лидеров
src/styles.css

assets/cards/*.svg     # собственные изображения карточек
```

Изображения нарисованы вручную в SVG, лицензионных ограничений нет.
